About This Page
Cities Dataset & Grid Overview

This page presents a dataset of {{ cities.length }} major world cities across all populated continents, rendered in a pure responsive CSS Grid data layout with real-time temperature values in both °F and °C.

Features & Implementation Methods
  • Responsive CSS Grid: Structured as a clean CSS Grid table displaying City Name, Country, and Current Temperature (°F & °C).
  • Separate Modal Component: The city details modal is implemented as its own standalone component (CityInfoModalComponent) with scrollable content.
  • Live Local City Clock: Calculates and ticks the real-time local time and date for the chosen city using its native IANA timezone identifier.
  • Dual Temperature Displays: Both the list grid and modal display temperatures in Fahrenheit (°F) and Celsius (°C).
  • Live Weather API: Fetches real-time temperature, condition codes, humidity, wind speed, and precipitation via the Open-Meteo free API using geographic coordinates (latitude / longitude).
  • Browser Back Button History: Uses ModalHistoryService (window.history.pushState & popstate). When the modal is open, pressing the browser ← Back button, clicking outside the modal backdrop, or pressing Esc closes only the modal without leaving the page.
  • Search & Filter: Fast client-side search across city name and country, with sorting.
