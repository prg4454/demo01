About To-Dos Management
Overview

The To-Dos Management component provides a structured, responsive task tracking system built with Angular 19, pure CSS Grid layout, and modal-based editing workflows.

Features & Implementation
  • Responsive CSS Grid Layout: Structured using fluid CSS Grid rows (todos-grid-row) matching the layout standard of Dogs, Customers, and Medicines.
  • Separate Add & Edit Modal: Powered by TodosEntryModalComponent with field validation, keyboard shortcuts (Enter to save), and delete confirmation dialogs.
  • Unsaved Changes Protection: Detects modifications between original and draft records, showing a field-by-field diff before discarding.
  • Browser History Integration: Uses ModalHistoryService to allow dismissing modals via browser ← Back button or Esc.
  • Quick Status Toggle: Checkboxes allow instantly toggling tasks between Completed and Pending directly from the grid.
  • Filtering & Sorting: Fast client-side multi-field search (title, category, assignee, notes), category filter, status filter, and pagination (8 items per page).
  • Export Support: Integrates with ExportDropdownComponent for exporting task data into CSV, JSON, or text formats.
