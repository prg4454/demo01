About This Page
Data Source

The data displayed here is fetched dynamically from jsonplaceholder.typicode.com, a free fake REST API.

Programming Methods
  • State Management: Uses standard Angular class properties (posts array and loading boolean) to manage the component's state.
  • HTTP Client: Utilized Angular's HttpClient to perform the asynchronous GET request within the ngOnInit lifecycle hook.
  • CSS Grid: Implemented a responsive custom CSS Grid for the layout instead of traditional UI cards. The row configuration uses grid-template-columns: 50px 50px repeat(auto-fit, minmax(150px, 1fr));.
  • Column Spanning: The Title cell is forced to span the remainder of the row using grid-column: 3 / -1;, while the Body cell drops down to span the full width using grid-column: 1 / -1;.
  • ng-bootstrap Modal: This modal is built using NgbModal from the ng-bootstrap library.
